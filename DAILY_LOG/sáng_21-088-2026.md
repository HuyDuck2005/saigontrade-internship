Triển khai và kiểm thử thực tế các **Task 5, Task 6, Task 7 và Task 8** trong dự án tích hợp hệ thống CRM qua giao thức **XML-RPC** và xây dựng **REST API Middleware**. ## 3. Chi tiết các công việc đã thực hiện

### 🔹 Task 5: Tạo CRM Lead trực tiếp trên Odoo (XML-RPC)
* **Xây dựng & Kiểm thử**: 
  * Sử dụng module `OdooCRMClient` để xác thực và tạo Lead thông qua XML-RPC.
  * Thực thi kịch bản `python3 tests/test_task5_real.py` để kết nối trực tiếp vào Odoo 1.
* **Kết quả**: Xác thực thành công tài khoản quản trị (UID: 2) và tạo thành công Lead/Deal mới trên hệ thống Odoo CRM.

### 🔹 Task 6: Đồng bộ Contact đa hệ thống (Odoo 1 ➔ Odoo 2)
* **Logic xử lý**:
  * Phát triển kịch bản `python3 tests/test_task6_flow.py` để kết nối đồng thời tới Odoo 1 (`8069`) và Odoo 2 (`8070`).
  * Áp dụng logic **Upsert** dựa trên số điện thoại (tìm kiếm trước, nếu có thì cập nhật, nếu chưa có thì tạo mới) để đồng bộ contact `Lê Hoàng Nam` từ Odoo 1 sang Odoo 2.

### 🔹 Task 7: Mapping & Tự động tạo Custom Fields
* **Xử lý kỹ thuật**:
  * Thiết lập ánh xạ 20 trường dữ liệu tùy chỉnh (`x_`) qua lại giữa hai hệ thống.
  * Xử lý các vấn đề nghẽn mạng (Timeout) do Odoo tự động nạp lại cấu hình cơ sở dữ liệu (`Registry Reload`) liên tục khi tạo cột vật lý qua XML-RPC.

### 🔹 Task 8: REST Wrapper API (FastAPI + Idempotency + Audit Log)
* **Phát triển Middleware**:
  * Khởi chạy Server FastAPI tại cổng `8080` (`src/odoo/task8_deal_middleware.py`).
  * Tích hợp bảo mật header với khóa `X-API-Key: sgt_secret_api_key_2026`.
  * Cấu hình cơ chế **Idempotency-Key** để ngăn chặn việc tạo trùng lặp Deal khi request bị bắn lặp lại nhiều lần.
  * Tích hợp ghi nhận lịch sử thao tác vào **Audit Log**.

## 4. Vấn đề phát sinh & Cách khắc phục

| Vấn đề phát sinh | Nguyên nhân | Hướng xử lý |
| :--- | :--- | :--- |
| **`cannot execute: required file not found`** | Môi trường ảo `venv` bị gãy đường dẫn tuyệt đối sau khi đổi tên thư mục dự án. | Xóa thư mục `venv` cũ, tạo lại venv mới (`python3 -m venv venv`) và cài lại các thư viện. |
| **`Connection Refused` khi gọi Odoo 2** | Chưa khởi động container Odoo 2 hoặc chưa tạo cơ sở dữ liệu `odoo2_db`. | Dựng cụm Docker Compose cho Odoo 2 ở cổng `8070`, tạo DB `odoo2_db` và cài đặt module CRM. |
| **Lỗi `ERR_ADDRESS_INVALID` trên trình duyệt** | Truy cập nhầm vào địa chỉ `--host 0.0.0.0`. | Thay đổi địa chỉ truy cập trên trình duyệt thành `http://localhost:8080` hoặc `http://localhost:8070`. |
| **Odoo sập nguồn khi chạy Task 7** | Gửi quá nhiều yêu cầu tạo cột DDL dồn dập qua XML-RPC làm nghẽn tiến trình `_auto_init`. | Khởi động lại container Odoo 2 (`docker compose restart`) để làm sạch tiến trình. |

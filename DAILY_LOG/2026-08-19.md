# NHẬT KÝ THỰC TẬP (19/08/2026)

## 1. Tổng quan công việc
Xây dựng và hoàn thiện hệ thống **Tích hợp & Đồng bộ 2 chiều giữa HubSpot CRM và Google Sheets**, hỗ trợ cơ chế đồng bộ định kỳ (Polling/Daemon), đồng bộ thời gian thực qua **Webhook (FastAPI)** kết hợp **Cloudflare Tunnel**, quản lý **Deals & Dashboard Báo cáo (Pandas)**, và ghi vết thay đổi toàn diện (**Audit Change Log**). Triển khai cấu trúc và đẩy toàn bộ mã nguồn lên GitHub repository `saigontrade-internship`.

## 3. Chi tiết các công việc đã thực hiện

### 🔹 Hạ tầng & Môi trường phát triển (WSL / Ubuntu)
* Cập nhật hệ thống Ubuntu (`apt update && apt upgrade`) và cài đặt các gói công cụ nền tảng: `python3`, `python3-pip`, `python3-venv`, `git`, `curl`, `build-essential`.
* Cấu hình quyền Docker socket cho user (`usermod -aG docker $USER`, `newgrp docker`) để quản lý container suôn sẻ.
* Khởi tạo thư mục dự án `~/projects/hubspot_tasks` và thiết lập môi trường ảo Python (`venv`).
* Cài đặt các thư viện lõi: `requests`, `gspread`, `google-auth`, `pandas`, `fastapi`, `uvicorn`, `python-dotenv`, `httpx`.
* Thiết lập cấu hình bảo mật qua `.env` (lưu trữ `HUBSPOT_ACCESS_TOKEN`, `SPREADSHEET_ID`, `GOOGLE_CREDENTIALS_FILE`) và kết nối thành công Google Service Account (`hubspot-bot@hubspot-sync-project.iam.gserviceaccount.com`).

---

### 🔹 Task 1: Đồng bộ dữ liệu Contact từ HubSpot về Google Sheets (`task1_hubspot_to_sheet.py`)
* **Lấy dữ liệu đầy đủ từ HubSpot CRM API** (`/crm/v3/objects/contacts`) kèm xử lý phân trang (`paging.next.after`).
* **Trích xuất các trường thông tin chuẩn:** Contact ID, Họ tên, Email, Số điện thoại, Mobile Phone, Công ty, Chức vụ, Website, Quốc gia, Lifecycle Stage, Create Date, Last Modified Date.
* **Cơ chế đối soát thông minh (Full & Incremental Sync):**
  * Tự động thêm mới (Append) các Contact mới xuất hiện trên HubSpot vào tab `Contacts`.
  * Cập nhật (Update) các Contact bị thay đổi thông tin.
  * Tự động phát hiện và loại bỏ các Contact đã bị xóa trên CRM khỏi Google Sheet, duy trì độ khớp 100%.
  * Tự động chuẩn hóa thời gian đồng bộ theo giờ Việt Nam (GMT+7).

---

### 🔹 Task 2: Import & Kiểm tra hợp lệ dữ liệu từ Sheet lên HubSpot (`task2_sheet_to_hubspot.py`)
* Đọc danh sách từ tab `Sheet_To_HubSpot` với các dòng trạng thái `NEW` hoặc cần Retry.
* **Cơ chế Validate dữ liệu đầu vào chặt chẽ:** Kiểm tra định dạng Email (`regex`), bắt lỗi trường bắt buộc trước khi gửi request tới HubSpot API.
* **Xử lý phản hồi 2 chiều:**
  * **Thành công:** Tạo Contact trên HubSpot CRM, lấy `HubSpot ID` trả về ghi ngược lại Sheet và đổi `status = SUCCESS`.
  * **Thất bại/Lỗi cú pháp:** Đổi `status = ERROR` và ghi chi tiết thông báo lỗi vào cột `error_message` để người dùng dễ kiểm tra và chỉnh sửa.

---

### 🔹 Task 3: Đồng bộ Deals & Xây dựng Dashboard Báo cáo (`task3_deal_to_sheet.py`)
* Kéo dữ liệu Deals từ HubSpot CRM API (`/crm/v3/objects/deals`): Deal ID, Deal Name, Amount, Pipeline, Deal Stage, Owner, Close Date, Create Date.
* Ghi dữ liệu chi tiết vào tab `Deals`.
* Sử dụng `pandas` tổng hợp và tự động dựng bảng báo cáo Dashboard tại tab `Summary` (Doanh thu theo Stage, số lượng Deal theo Pipeline, tổng giá trị Pipeline).

---

### 🔹 Task 4: Webhook Server Real-time (`task4_webhook_server.py` & `cloudflared`)
* Xây dựng REST API Server bằng **FastAPI** + **Uvicorn** chạy trên port `8000`.
* Sử dụng **Cloudflare Tunnel (`cloudflared`)** tạo cầu nối HTTPS công khai an toàn, ổn định và không giới hạn lưu lượng (thay thế ngrok).
* Định tuyến Endpoint `POST /hubspot/webhook` tiếp nhận sự kiện real-time từ HubSpot (`contact.propertyChange`, `contact.creation`).
* Xử lý bất đồng bộ qua `BackgroundTasks`, tự động định vị dòng tương ứng trên Google Sheet và cập nhật tức thì dữ liệu thay đổi chỉ trong ~1-2 giây.

---

### 🔹 Mở rộng: Audit Logging & Auto Daemon
* **Hệ thống Audit Log (`audit_logger.py`):**
  * Ghi nhận mọi biến động dữ liệu (Thêm, Sửa, Xóa) đa kênh: lưu file local `audit_change_log.csv`, `audit_change_log.json` và đồng bộ lên tab `Audit_Logs` trên Google Sheets.
  * Lưu đầy đủ thông tin: Timestamp (VN), Action, Object, ID, Nguồn thay đổi (Sheet/CRM/Webhook), Chi tiết thay đổi (Trường: Cũ -> Mới).
* **Tiến trình chạy tự động (`auto_sync_daemon.py` / `main.py`):**
  * Tích hợp Menu điều khiển trung tâm (`main.py`) cho phép chạy thủ công từng task hoặc chạy chu kỳ lặp tự động (Auto Loop).
  * Kiểm soát vòng lặp mượt mà, xử lý ngoại lệ và ngắt dừng an toàn (`KeyboardInterrupt`).

## 4. Vấn đề phát sinh & Cách khắc phục

| Vấn đề phát sinh | Nguyên nhân | Hướng xử lý |
| :--- | :--- | :--- |
| **Cần mở cổng Webhook từ Internet về localhost không dùng ngrok** | Ngrok bản miễn phí bị giới hạn session, bắt buộc đăng nhập và hay bị trang cảnh báo làm chặn Webhook. | Sử dụng **Cloudflare Tunnel (`cloudflared.exe tunnel --url http://localhost:8000`)** cho đường truyền HTTPS nhanh, ổn định và không cần tài khoản. |
| **Lỗi `permission denied` khi chạy `docker ps`** | User `huyduc` chưa nhận nhóm quyền `docker` trong session hiện tại. | Thêm user vào group `docker` (`usermod -aG docker $USER`) và kích hoạt ngay bằng `newgrp docker`. |
| **Lỗi `SpreadsheetNotFound` (404) trong gspread** | Truyền nhầm toàn bộ URL Google Sheets vào biến `SPREADSHEET_ID`. | Cắt lấy chính xác ID của Sheet trong URL (`1v_EXkd3HeQYgEaaL6MTDRoItcDGUWSse53J5mMA1xvE`) và đưa vào `.env`. |
| **Lỗi `APIError [403]: The caller does not have permission`** | Chưa chia sẻ quyền Chỉnh sửa (Editor) của file Sheet cho Email Service Account. | Lấy email Service Account (`hubspot-bot@...`) chia sẻ quyền Editor trực tiếp trên Google Drive/Sheets. |
| **HubSpot API trả về lỗi `400 INVALID_EMAIL` khi Import** | Dòng dữ liệu test nhập email sai định dạng (ví dụ `saiformat_email`, `as`). | Thêm hàm `is_valid_email()` lọc trước trên code, cập nhật trạng thái `ERROR` kèm lý do vào cột `error_message` trên Sheet. |
| **Menu `main.py` bị kẹt vòng lặp khi nhận chuỗi ký tự lạ** | Lệnh paste code shell đè vào `input()` của terminal đang mở. | Dùng `Ctrl+C` ngắt tiến trình sạch sẽ, hoàn thiện lại luồng điều khiển trong `main.py`. |
| **Lỗi xác thực Git `Password authentication is not supported`** | GitHub không còn hỗ trợ mật khẩu tài khoản khi push/clone qua CLI. | Tạo GitHub Personal Access Token (`ghp_...`) với quyền `repo` và cấu hình lưu qua `credential.helper store`. |

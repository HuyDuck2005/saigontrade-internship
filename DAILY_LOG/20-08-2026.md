# NHẬT KÝ THỰC TẬP (20/08/2026)

## 1. Tổng quan công việc
Triển khai hệ thống **Đồng bộ dữ liệu CRM giữa Odoo 1 và Odoo 2** thông qua **XML-RPC API**. Hoàn thiện module Odoo (`sgt_odoo_sync`) bao gồm tính năng tạo Contact/Deal tự động, xử lý trạng thái đồng bộ (Sync Status), cơ chế Retry khi lỗi, và tích hợp middleware API (`Task 8`) để nhận dữ liệu từ HubSpot chuyển tiếp vào Odoo CRM.

## 3. Chi tiết các công việc đã thực hiện

### 🔹 Task 5, 6, 7: Đồng bộ & Mapping dữ liệu Odoo
* **Xây dựng module `sgt_odoo_sync`**:
  * Phát triển giao diện XML tùy chỉnh cho `crm.lead`: Thêm nút **"Tạo Contact Odoo1 & Odoo2"** và **"Thử lại đồng bộ (Retry)"**.
  * Bổ sung Tab **"Trạng thái Sync Odoo 2"** để quản lý: `sync_status` (Selection), `remote_partner_id`, `sync_error_msg`.
* **Logic đồng bộ (Backend Python)**:
  * Viết hàm `action_create_contact_both` sử dụng `xmlrpc.client.ServerProxy` kết nối tới URL `http://odoo2-app:8069`.
  * Thực hiện mapping dữ liệu: `name`, `phone`, `email`, `function`, `mobile`, `website` từ Lead Odoo 1 sang `res.partner` của Odoo 2.
  * Xử lý lỗi (Exception Handling) và cập nhật trạng thái `failed/success` vào Database.

### 🔹 Task 8: Middleware API
* Hoàn thiện API trung gian (`src.odoo.task8_deal_middleware:app`) chạy trên port `8000`.
* Định nghĩa endpoint `POST /api/crm/deal` với bảo mật API Key: `sgt_secret_api_key_2026`.

### 🔹 Quản trị môi trường & Bảo mật
* **Cấu hình Remote Odoo**: Thiết lập kết nối tại menu *Sync Odoo2 > Configuration* với thông tin:
  * **URL:** `http://odoo2-app:8069`
  * **Database:** `odoo2_db`
  * **Username:** `admin` / **Password:** `admin`
* **Git Authentication**: Chuyển đổi phương thức xác thực sang **GitHub CLI (`gh auth login`)** để giải quyết lỗi không hỗ trợ mật khẩu Git truyền thống.

## 4. Vấn đề phát sinh & Cách khắc phục

| Vấn đề phát sinh | Nguyên nhân | Hướng xử lý |
| :--- | :--- | :--- |
| **Lỗi XML Schema (500)** | Dư thừa thẻ `<data>` hoặc cấu trúc thẻ sai Odoo 17. | Xây dựng lại cấu trúc XML chuẩn (dùng thẻ `<record>` trực tiếp). |
| **Odoo Session Expired** | Xung đột Cookie giữa 2 tab Odoo (cùng chạy trên `localhost`). | Truy cập Odoo 2 qua IP ảo `http://127.0.0.1:8070` để tách biệt Session. |
| **Nút bấm bị kẹt (loading)** | Hàm Python thiếu lệnh trả về (Return) yêu cầu trình duyệt tải lại trang. | Bổ sung `return {'type': 'ir.actions.client', 'tag': 'reload'}` vào hàm Python. |
| **Dữ liệu thiếu trên Odoo 2** | Code chưa map hết các trường: Job Position, Mobile, Website. | Cập nhật lại từ điển `partner_vals` để bao gồm các trường mở rộng. |
| **Lỗi xác thực Git** | GitHub ngừng hỗ trợ mật khẩu tài khoản CLI. | Sử dụng `gh auth login` để xác thực qua trình duyệt. |

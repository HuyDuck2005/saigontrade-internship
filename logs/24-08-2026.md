# BÁO CÁO KỸ THUẬT TÍCH HỢP GOOGLE SHEET VÀ HUBSPOT CRM (MODULE CONTACTS)

## 1\. Tổng quan các công việc đã thực hiện

Trong quá trình triển khai dự án, hệ thống đã được xây dựng và tối ưu hóa để quản lý thông tin khách hàng cốt lõi giữa Google Sheet và HubSpot CRM theo chuẩn nghiệp vụ doanh nghiệp.

Cụ thể

Xây dựng cấu trúc dữ liệu nền tảng (Task 1) Thiết lập Tab `Contacts` trên Google Sheet chứa thông tin chi tiết khách hàng gồm Họ tên, Email, Số điện thoại, Công ty, Chức danh và Quốc gia.
Cơ chế tự động hóa và Menu tiện ích (Task 2) Tạo Menu tùy chỉnh `HubSpot Sync` trực tiếp trên thanh công cụ Google Sheet giúp người dùng thao tác thuận tiện mà không gặp lỗi phân quyền ngầm `external\_request`.
Tối ưu hóa nghiệp vụ thông minh (Task 3 \& Vận hành)

Lập trình cơ chế nhận diện thông minh Khi người dùng nhập `NEW` hoặc `UPDATE` tại cột trạng thái (`status`), hệ thống tự động kiểm tra khách hàng đã tồn tại trên HubSpot hay chưa để quyết định tạo mới (`POST`) hoặc cập nhật (`PATCH`).
Tự động biến ID khách hàng tại Cột A thành Hyperlink dẫn trực tiếp đến trang chi tiết của khách hàng trên HubSpot.
Kiểm toán hệ thống và ghi nhận lịch sử (Task 4) Xây dựng tab `Audit\_Logs` tự động ghi nhận nhật ký thao tác gồm Thời gian, Hành động, Đối tượng, Mã ID, Trạng thái và nội dung đồng bộ.

function searchHubSpotContact(email, phone) {

  var url =
    httpsapi.hubapi.comcrmv3objectscontactssearch;

  var filters = \[];

  if (email) {
    filters.push({
      propertyName email,
      operator EQ,
      value email.toString().trim()
    });

  } else if (phone) {

    filters.push({
      propertyName phone,
      operator EQ,
      value phone.toString().trim()
    });
  }

  if (filters.length === 0) {
    return null;
  }

  var options = {
    method post,
    contentType applicationjson,
    headers {
      Authorization Bearer  + HUBSPOT\_TOKEN
    },
    payload JSON.stringify({
      filterGroups \[
        {
          filters filters
        }
      ],
      limit 1
    }),
    muteHttpExceptions true
  };

  var res = UrlFetchApp.fetch(url, options);

  if (res.getResponseCode() === 200) {

    var result = JSON.parse(
      res.getContentText()
    );

    if (
      result.results \&\&
      result.results.length  0
    ) {
      return result.results\[0].id;
    }
  }

  return null;
}

## 3\. Các cải tiến kỹ thuật chính

### 3.1. Tối ưu hóa gọi API qua `UrlFetchApp`

Hệ thống sử dụng `UrlFetchApp.fetch()` để giao tiếp trực tiếp với HubSpot CRM API.

Thiết lập

```javascript
muteHttpExceptions true
```

giúp hệ thống không dừng toàn bộ script ngay khi HubSpot trả về lỗi HTTP. Thay vào đó, response được đọc và xử lý để cập nhật trạng thái lỗi trực tiếp trên Google Sheet.

\---

### 3.2. Xử lý và chuẩn hóa dữ liệu

Hệ thống thực hiện Data Sanitization trước khi gửi dữ liệu lên HubSpot.

Ví dụ

```javascript
.toString()
.trim()
.replace(\[']+g, '')
```

Mục đích

Loại bỏ khoảng trắng thừa.
Chuẩn hóa kiểu dữ liệu.
Loại bỏ dấu nháy không cần thiết khỏi Contact ID.
Hạn chế lỗi khi dữ liệu được nhập thủ công trên Google Sheet.

\---

### 3.3. Cơ chế nhận diện Contact

Hệ thống ưu tiên sử dụng Contact ID có sẵn tại Cột A.

Nếu không có ID, hệ thống sẽ thực hiện tìm kiếm trên HubSpot dựa trên

1. Email.
2. Phone nếu Email không tồn tại.

Logic tổng quát

```text
Có Contact ID
    
    +-- Có -- UPDATE Contact
    
    +-- Không
          
          +-- Tìm bằng EmailPhone
                  
                  +-- Tìm thấy -- UPDATE
                  
                  +-- Không tìm thấy -- CREATE
```

\---

### 3.4. Tự động tạo Hyperlink

Sau khi đồng bộ thành công, hệ thống tự động tạo đường dẫn trực tiếp đến Contact trên HubSpot.

Ví dụ

```text
httpsapp-na2.hubspot.comcontacts{PORTAL\_ID}record0-1{CONTACT\_ID}
```

Trên Google Sheet, Contact ID tại Cột A sẽ được hiển thị dưới dạng hyperlink.

Điều này giúp người dùng có thể nhấp trực tiếp vào ID để mở hồ sơ Contact tương ứng trên HubSpot.

\---

### 3.5. Kiểm toán dữ liệu (Audit Trail)

Hệ thống sử dụng tab `Audit\_Logs` để lưu lại lịch sử đồng bộ.

Các thông tin được ghi nhận gồm

Trường       Ý nghĩa

\---

Timestamp    Thời gian thực hiện  
Action       CREATE hoặc UPDATE  
Object       Đối tượng được xử lý  
ID           Contact ID trên HubSpot
Source       Nguồn dữ liệu  
User         Người thực hiện  
Description  Nội dung thao tác

Cơ chế này giúp doanh nghiệp có thể theo dõi lịch sử thay đổi và kiểm tra lại các hoạt động đồng bộ dữ liệu.

## 5\. Hướng dẫn vận hành sau khi tắt máy  mở lại file

Do Google Sheet và Google Apps Script hoạt động trên nền tảng Cloud, việc tắt máy không làm mất mã nguồn hoặc cấu hình của hệ thống.

Khi mở lại file vào ngày hôm sau, thực hiện các bước sau.

### Bước 1 Mở Google Sheet

Truy cập vào file Google Sheet của dự án.

\---

### Bước 2 Kiểm tra Menu hệ thống

Tải lại trang bằng `F5`.

Sau khi tải lại, kiểm tra thanh công cụ phía trên và xác nhận menu

```text
HubSpot Sync
```

đã xuất hiện.

\---

### Bước 3 Nhập thông tin khách hàng

Tại tab

```text
Contacts
```

nhập thông tin khách hàng mới hoặc chỉnh sửa thông tin khách hàng hiện có.

\---

### Bước 4 Nhập trạng thái

Tại Cột O (`status`)

Nhập `NEW` đối với Contact mới.
Nhập `UPDATE` đối với Contact cần cập nhật.

Ví dụ

```text
NEW
```

hoặc

```text
UPDATE
```

\---

### Bước 5 Chạy đồng bộ

Trên thanh menu Google Sheet, chọn

```text
HubSpot Sync
    ↓
Đồng bộ Contacts (NEWUPDATE)
```

Hệ thống sẽ tự động

1. Kiểm tra Contact.
2. Tìm kiếm Contact trên HubSpot nếu cần.
3. Tạo mới hoặc cập nhật Contact.
4. Cập nhật Contact ID.
5. Tạo Hyperlink.
6. Cập nhật thời gian đồng bộ.
7. Ghi Audit Log.
8. Cập nhật trạng thái xử lý.

\---

### Bước 6 Kiểm tra kết quả

Sau khi quá trình hoàn tất, kiểm tra

Cột A Contact ID chuyển thành hyperlink.
Cột N Có thời gian đồng bộ.
Cột O Hiển thị `SUCCESS` hoặc `UPDATED`.
Tab `Audit\_Logs` Có bản ghi lịch sử tương ứng.
HubSpot CRM Contact được tạo mới hoặc cập nhật chính xác.

## 6\. Các trạng thái xử lý

Trạng thái                Ý nghĩa

\---

`NEW`                     Yêu cầu tạo hoặc đồng bộ Contact mới
`UPDATE`                  Yêu cầu cập nhật Contact  
`SUCCESS`                 Tạo Contact thành công  
`UPDATED`                 Cập nhật Contact thành công  
`LỖI Thiếu EmailPhone`  Không đủ dữ liệu định danh  
`ERROR ...`              HubSpot API hoặc hệ thống trả về lỗi

## 7\. Kết luận

Hệ thống Google Sheet – HubSpot CRM đã được xây dựng thành công với khả năng đồng bộ dữ liệu Contact hai chiều theo quy trình nghiệp vụ rõ ràng.

Các chức năng chính bao gồm

Quản lý dữ liệu Contact trên Google Sheet.
Tạo Contact mới trên HubSpot.
Cập nhật Contact đã tồn tại.
Tự động tìm kiếm Contact bằng EmailPhone.
Tự động tạo Hyperlink đến hồ sơ Contact.
Ghi nhận thời gian đồng bộ.
Ghi Audit Trail.
Xử lý và hiển thị lỗi trực tiếp trên Google Sheet.
Cung cấp Menu `HubSpot Sync` giúp người dùng vận hành dễ dàng.

Giải pháp giúp giảm thao tác thủ công, hạn chế sai sót khi nhập dữ liệu và tạo nền tảng để mở rộng hệ thống đồng bộ sang các module khác của HubSpot CRM trong các Task tiếp theo.
